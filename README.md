# Active Directory User Management & Administration

This project demonstrates setting up and administering a Windows Active Directory environment, focusing on user accounts, groups, permissions, authentication, and common account-management tasks relevant to IT Help Desk and Technical Support roles.

## Environments and Technologies Used

* Windows Server
* Windows Client
* Active Directory Domain Services
* Active Directory Users and Computers
* DNS
* Group Policy
* PowerShell *(if used)*

## Project Overview

This project will document the process of configuring an Active Directory environment and performing common administrative and support tasks.

The project will include:

* Installing and configuring Active Directory Domain Services
* Creating and organizing users and Organizational Units
* Creating and managing security groups
* Joining a Windows client computer to the domain
* Managing user passwords
* Unlocking user accounts
* Enabling and disabling accounts
* Managing group membership
* Configuring Group Policy
* Testing and verifying changes
* Documenting troubleshooting encountered during the project
